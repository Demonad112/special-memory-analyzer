Install

About 2 minutes · needs administrator

  1. Open the latest release and download …_x64-setup.exe, plus SHA256SUMS-release.txt.

  2. Check the hash and compare it with the sums file:

    Get-FileHash ".\Deep Server Analyzer_<version>_x64-setup.exe" -Algorithm SHA256

  3. Run the installer. If SmartScreen shows Windows protected your PC, choose More info, then Run anyway. The warning appears because the signing certificate is self-signed.

  4. Accept the administrator prompt. The app installs for all users into C:\Program Files\Deep Server Analyzer.

Silent install (scripts, RMM)

"Deep Server Analyzer_<version>_x64-setup.exe" /S
The installer downloads the WebView2 runtime if it is not already on the PC. Edge or Chrome may say the file “isn't commonly downloaded”: choose Keep, then Keep anyway.

Install on a server with the USB kit

About 5 minutes · needs administrator

Servers often block unknown publishers. The kit trusts the release certificate for a limited time, installs the app, and removes trust again on a schedule.

  1. On a PC with internet, download Deep-Server-Analyzer-usb-kit.zip from the release and note the Thumbprint (SHA-1) from the release notes. Copy the zip to the server on a USB stick.

  2. On the server, right-click the zip → Properties → Unblock, then extract the whole zip to a folder. Do not run it from inside the zip.

  3. Double-click DSA-Installer.cmd and accept the administrator prompt. If SmartScreen appears, choose More info → Run anyway.

  4. Paste the full thumbprint from the release page. The Install button stays disabled until it matches.

  5. Choose how long trust lasts: 1, 4, 8 (default), 12 or 24 hours, a custom time (15 minutes to 72 hours), or remove it right after install.

  6. Click the blue Install button. The kit verifies itself, trusts the certificate, schedules removal and runs the silent setup. The window shows Installed and a countdown.

  7. To finish early, click the red ✕ Remove trust. An OK/FAIL checklist runs and the window turns green with Trust removed and verified. Use ▲ +1 h to extend (maximum 72 hours from now).

While trust is active it is machine-wide. Only run the kit on servers you are authorised to change. AppLocker or WDAC can block it, and endpoint protection may flag the certificate change or the scheduled task DSA-TrustExpiry. Ask the security team first if in doubt.

Unattended

Install-DSA.ps1 -NoPrompt -ExpectedThumbprint <full thumbprint> -TrustHours 8

Other switches: -RemoveAfterInstall, -SkipInstall. Details are in the USB install notes.

Not sure whether anything is still trusted? Run Remove-Trust.cmd. It is safe when nothing is trusted. Log: C:\ProgramData\DSA\trust.log.

Compare two folders

Left nav → Compare & Record

  1. Choose the Source and the Destination. The swap button flips them. Recent pairs on Home reopen the same comparison.

  2. Optional boxes:

    • Also compare file contents is slower because every file is read twice.
    • Ignore system and temp files skips Thumbs.db, desktop.ini, ~$ Office lock files and .tmp.

  3. Start the compare. Cancel (Esc) stops it.

  4. Use the chips All, Differences and Missing to focus the list. Folders that cannot be read, and online-only cloud files, are shown as notices.

  5. Compare again after fixing things, or open the saved report in the browser to print or save as PDF.

Record a copy

From a compare result, click Copy every missing file, or open Record directly

  1. Pick a mode:

    • Watch: another program does the copy (Explorer, robocopy, a backup tool) and the app checks every file that arrives. Button: Start watching.
    • Copy for me: the app copies, retries files in use and verifies each copy. Button: Start copy.

  2. If a file already exists at the destination, choose one:

    • Leave it and list the file as not copied (default)
    • Replace it only if the source is newer
    • Replace it
    • Keep both (saves the source as name (2).ext)

  3. Tick what to Keep: dates, attributes, permissions, owner (administrator), audit rules (administrator), alternate data streams.

  4. Leave Download OneDrive online-only files off unless you want them pulled down. Off means they are listed as not copied.

  5. Watch the live counters: Files, Size, Speed, Not copied and the current file.

  6. In Watch mode, press Finish and check when the other copy is done. The report lists every file that did not make it, in red, with the reason.

A scan and an elevated (administrator) record cannot run at the same time. The second one is refused with a message. Finish or cancel the first.

Retry missed files

  1. Open the record report from Recent records or Reports.

  2. Fix the cause shown beside each red file: close the program that holds it, rename an invalid name, or reconnect the share.

  3. Choose Retry. Only the files that did not make it are copied again. A run that was cancelled or killed shows Cancelled, and Retry covers the files it never reached.

Clean up a disk

Left nav → Disk Cleanup

  1. Pick a tile under Drives on this PC, or type a path under Or scan one folder. Esc cancels a scan.

  2. Read the treemap, Largest files and File types. Open a folder to drill in; Backspace goes up one folder.

  3. Switch between Size on disk (what deleting frees) and Size (what Explorer shows).

  4. Right-click an item: Show in Explorer, Copy path or Move to Recycle Bin. Shift+Delete deletes permanently.

  5. Try Quick cleanups for common junk. System ones need administrator and Windows asks first.

  6. Bulk and permanent deletes show a confirmation such as This is a big cleanup. Read it before confirming.

The app never deletes its own data folder, and a built-in never-delete list protects system locations. Every delete is logged to Logs\deletions.jsonl.

Restore a cleanup

  1. In Disk Cleanup choose Restore last cleanup.

  2. Confirm. Items sent to the Recycle Bin by the last bulk run go back to where they were. Only the last bulk run is restored. Permanently deleted items cannot be restored.

Export a report

Left nav → Reports

  1. Filter by All, Compare, Record, Disk usage or Cleanup, or search by client, ticket or folder.

  2. Use the row actions:

    • Open in browser: print or save as PDF from there.
    • Export as HTML: one standalone page for the client.
    • Export as CSV: for Excel.

  3. Put your name on reports in Settings (company name and logo).

Settings

Option What it does
App theme Light, Dark, or Use Windows setting.
Company name on reports Shown on exported reports.
Company logo Choose… or Change… to set the logo on reports.
Include job details in CSV Adds job information to CSV exports.
Keep saved reports Keep for ever (default), 30 days, 90 days or 1 year.
Close after inactivity Off, or a delay; the default is 30 minutes. A warning appears first with a stay-open option.

Portable mode and data folders

  • Default data: %LOCALAPPDATA%\Deep Server Analyzer\ with Records, Reports and Logs.
  • Portable: create a file named portable.txt next to the exe. Data then lives in a Data folder beside it. Delete the file to go back.
  • Override locations with DEEP_SERVER_ANALYZER_RECORDS_DIR, DEEP_SERVER_ANALYZER_REPORTS_DIR and DEEP_SERVER_ANALYZER_LOGS_DIR.
  • Theme, recent folders and company name stay in the web view on that PC, not in Data.

Uninstall

  1. Windows Settings → Apps → Installed apps → Deep Server Analyzer → Uninstall. Or run silently: 

    "C:\Program Files\Deep Server Analyzer\uninstall.exe" /S

  2. If you used the USB kit, make sure trust is gone (run Remove-Trust.cmd), then delete the kit folder and, optionally, C:\ProgramData\DSA.

  3. Saved reports stay in your data folder until you delete them.
