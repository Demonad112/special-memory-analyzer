Features

Built for people who copy and clean other people's servers and need proof of what happened.

Size and hash compare

Fast size compare by default. Tick the option to also compare contents when sizes match.

Watch or Copy for me

Check files another tool copies (Explorer, robocopy, a backup agent), or let the app copy and verify.

Keeps the details

Choose to keep dates, attributes, permissions, owner, audit rules and alternate data streams.

If it already exists

Leave it and list it, replace if newer, replace, or keep both as name (2).ext.

Network-friendly

Dropped SMB connections are retried, and files in use are retried before being reported.

Client-ready reports

Export a standalone HTML page or a CSV for Excel, with your company name and logo. Print to PDF from the browser.

Recycle Bin first

Deletes go to the Recycle Bin by default. Permanent and big runs need administrator and confirmation.

Portable option

Drop a portable.txt beside the exe to keep records, reports and logs in a Data folder.

Migration readiness

Scan a source before a move for names that will fail at the target, broken permissions and locked files. Export the permissions as CSV.

Copy changes since this run

A short final pass at cutover that copies only what changed since an earlier Record run.

Duplicates, stale data and owners

Find duplicate files, stale folders and space by owner, then clean up from the Recycle Bin-first list.

Growth and forecast

Every scan is kept, so you can see what grew since last time and when the disk will fill.

Servers and shares

Use \\server\share or \\server\C$ anywhere. Server profiles never save a password, and shares are scan and report only.

Migration runbook

Combine readiness, Record and compare reports into one document, branded with your logo and a "Prepared for" block.

Careful by design

Cleanup tools get trusted with other people's data. These guardrails are built in.

  • Every delete goes through one pipeline and is written to Logs\deletions.jsonl.
  • A never-delete list is checked after resolving 8.3 names, \\localhost\c$ paths and subst drives.
  • Folder walks never follow symlinks, junctions or mount points.
  • Online-only OneDrive files are flagged and never opened, hashed or read.
  • Nothing is deleted on a network share or mapped drive, and saved server profiles never hold a password.
  • Saved files are written atomically, and exported HTML is escaped with a content security policy.
  • The app closes after inactivity (30 minutes by default) and warns first.

Verify before you run

Release builds are signed with a self-signed certificate created for each release, so Windows SmartScreen still warns. Checking the thumbprint and hash is how you know the file is the real one.

1. Match the thumbprint

The release notes and the download box above list the full SHA-1 thumbprint, but they are served from the same place as the file, so a match with the page alone proves nothing. Compare it with a copy from a channel you trust: the value your admin gave you, or the one in the USB kit's dsa-signing.cer that you received through your own channel. The USB kit's Install button stays disabled until the thumbprint you paste matches.

2. Check the hash

Get-FileHash .\Deep-Server-Analyzer-usb-kit.zip -Algorithm SHA256

Compare with SHA256SUMS-release.txt from the same release.

3. Check build provenance

With the GitHub CLI installed:

gh attestation verify <file> --repo Demonad112/special-memory-analyzer
Browser warning? Edge or Chrome may say the file “isn't commonly downloaded”. Choose Keep, then Keep anyway, then verify as above.
