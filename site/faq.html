Install and trust

Why does Windows say “Windows protected your PC”?

Release builds are signed with a self-signed certificate that is created for each release. Windows does not trust it, so SmartScreen warns. Click More info → Run anyway after you have verified the thumbprint and hash.

Edge or Chrome says the file “isn't commonly downloaded”.

Same cause: a new, low-volume file. Choose Keep, then Keep anyway, then check the SHA-256 against SHA256SUMS-release.txt.

Why a different certificate for every release?

The certificate is created for one release and its private key is deleted afterwards. A release can never be re-signed, and a stolen key cannot sign anything later. The trade-off is that you must check the thumbprint each time. It is a self-signed code-signing certificate, RSA 3072, valid 180 days, and the installer is timestamped.

Which download do I need, installer or USB kit?

Use the installer on workstations. Use the USB kit on servers where unknown publishers are blocked or where you must carry the files in. The kit contains the same installer plus scripts that trust the certificate temporarily.

What does the USB kit change on the server?

It adds the release certificate to LocalMachine\Root and LocalMachine\TrustedPublisher, runs the silent setup, and creates a scheduled task DSA-TrustExpiry (runs as SYSTEM, also at startup) that removes trust when time is up. Trust lasts 8 hours by default and can be 15 minutes to 72 hours. Removing it earlier is one click on ✕ Remove trust.

While trust is active it applies to the whole machine, so only use the kit on servers you are authorised to change.

What are the system requirements?

Windows 10 or 11, or Windows Server 2016 or newer with Desktop Experience, 64-bit. The WebView2 runtime is needed; the installer downloads it if it is missing.

Does it update itself or phone home?

No. There is no auto-update and no network code in the app. To update, download a newer release and install over the old one. This website reads release details from GitHub in your browser; the app does not.

Safety

Will Disk Cleanup delete things permanently?

By default deletes go to the Recycle Bin. Shift+Delete deletes permanently. Permanent and big runs need administrator rights and a confirmation. Every delete is logged in Logs\deletions.jsonl.

Can I undo a cleanup?

Restore last cleanup restores the last bulk run, checking where each item goes back to. Items that were deleted permanently cannot be restored. Single items you sent to the Recycle Bin can be restored from the Recycle Bin itself.

Is anything protected from deletion?

Yes. A never-delete list covers system locations and the app's own data folders. Paths are resolved first, so short 8.3 names, \\localhost\c$ paths and subst drives cannot slip past it. Folder walks do not follow symlinks, junctions or mount points.

Will it download my OneDrive files?

No. Online-only OneDrive and cloud files are flagged and never opened, hashed or read. In Record, Download OneDrive online-only files is off by default, which lists them as not copied.

Why did the app close by itself?

It closes after inactivity (30 minutes by default) so it is not left open on a server. A warning with a stay-open option appears first. Change it in Settings → Close after inactivity.

Compare and Record

Compare says files match, but are they identical?

The default compares by size, which is fast but not proof. Tick Also compare file contents to hash both sides. It is slower because every file is read twice.

Watch or Copy for me: which one?

Use Copy for me when the app can do the job; it retries files in use and verifies each copy before it replaces anything. Use Watch when another program has to do the copy (robocopy, Explorer, a backup agent) and you want an independent check of every file that arrives.

A file shows as not copied. What now?

The report lists every miss in red with its reason (in use, invalid name, online-only, access denied, and so on). Fix the cause and use Retry; only the misses are copied again. A run that was cancelled or crashed shows Cancelled and Retry also covers the files it never reached.

What if the network drops mid-copy?

Drops on SMB shares are retried automatically. Anything that still fails is listed as not copied so you can retry it.

Can I keep owner, permissions and audit rules?

Yes, under Keep on the Record page: dates, attributes, permissions, owner, audit rules and alternate data streams. Owner and audit rules need administrator.

Why was my Record or scan refused?

An elevated (administrator) record changes what the process can read, so it cannot overlap a running Compare or Disk Cleanup scan. Finish or cancel the first, then start the second.

Reports and data

Where are my reports and logs?

%LOCALAPPDATA%\Deep Server Analyzer\ holds Records, Reports and Logs. With portable.txt next to the exe they live in Data\ beside it. Override with DEEP_SERVER_ANALYZER_RECORDS_DIR, …_REPORTS_DIR or …_LOGS_DIR. App errors go to Logs\app.log.

How do I get a PDF for the client?

In Reports, choose Open in browser, then print and select Save as PDF. Or use Export as HTML for a single standalone page, or Export as CSV for Excel.

Can I put my company name and logo on reports?

Yes: Settings → Company name on reports and Company logo.

How long are reports kept?

For ever by default. Settings → Keep saved reports can change that to 30 days, 90 days or 1 year.

Is exported HTML safe to open or forward?

Exported pages escape file names and use a content security policy. CSV exports defuse spreadsheet formulas so a hostile file name cannot run when opened in Excel.

Troubleshooting

What you see What to do
“Smart App Control blocked a file” Unblock the files, then try again: Get-ChildItem "<kit folder>" -Recurse | Unblock-File
Install button is greyed out You opened the file from inside the zip or from a partial copy. Extract the whole zip first.
The window never opens Click Yes on the administrator prompt. If you clicked No, double-click again.
Thumbprint does not match the release page Stop. Download the zip again from the real Releases page.
Install failed Read the message, then see C:\ProgramData\DSA\trust.log. Nothing stays trusted after a failure.
Company security software blocks the scripts Ask the security team first. The kit changes certificate stores and adds a scheduled task.
Not sure whether anything is still trusted Run the red button or Remove-Trust.cmd. It is safe when nothing is trusted.
The app window is blank or will not start.

The app needs the WebView2 runtime. Reinstall with the installer, which downloads WebView2 if it is missing, then check Logs\app.log for the error.

I found a bug or want a feature.

Open an issue on GitHub. Attach the relevant lines of Logs\app.log; do not paste anything confidential.
